Technologies Used: HTML5, CSS3, Vanilla JavaScript

JavaScript Features Implemented:
1. Live book search/filter — filters the Featured Books cards by
   title and category as the user types in the search box.
2. Newsletter email validation — validates the email format with
   a regex pattern and displays a success or error message without
   submitting to a real server.
3. DOM interaction — smooth scrolling navigation, an "Explore Books"
   button that scrolls to the featured section, a "View All" link,
   and "View Details" buttons that display book information.

Description:
A responsive recreation of the EduBooks book-resource website,
built with semantic HTML, CSS Grid/Flexbox, and vanilla JavaScript.
Includes navigation, hero, features, featured books, newsletter,
and footer sections. Fully responsive across desktop, tablet, and
mobile screen sizes.
